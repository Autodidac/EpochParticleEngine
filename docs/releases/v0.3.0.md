# EpochParticleEngine v0.3.0

v0.3.0 replaces the legacy CPU-expanded bitmap text path with compact GPU-rasterized glyphs and synchronizes the optional UI adapter with EpochGui v0.87.43.

## Root cause

`RenderFrame::text` previously converted each lit 5x7 bitmap cell into a separate rectangle. Fractional cell sizes left gaps between those rectangles, producing missing or broken vertical strokes, while direct scene text calls could bypass the declared 12-pixel readability floor. The adapter also referenced EpochGui headers and font constants that no longer exist in the current mirror.

## Fixed

- Each visible character is now one render item containing a packed 35-bit glyph.
- The Vulkan fragment shader selects glyph cells directly on the GPU.
- Glyph words remain integer data from CPU storage through shader lookup.
- All text roles enforce a minimum 12 logical pixels before DPI scaling.
- The optional adapter builds against EpochGui v0.87.43's current `epoch/gui` headers, namespace, C++ module, and selectable-list API.

## Validation

The release candidate passed:

- strict MSVC CPU Debug compilation and deterministic tests;
- strict MSVC Vulkan Release compilation with warnings as errors;
- an integration build of the real local EpochGui v0.87.43 checkout;
- runtime shader compilation on an NVIDIA GeForce RTX 5080;
- a rendered-window capture confirming complete glyph strokes and consistent sizing;
- clean `WM_CLOSE` shutdown with exit code zero; and
- source-package checksum and archive-integrity verification.

Release assets contain the source archive and its portable SHA-256 checksum.
