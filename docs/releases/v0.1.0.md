# EpochParticleEngine v0.1.0

Initial public release of the C++23 hybrid particle simulation library.

## Highlights

- Deterministic fixed-point particles, cellular automata, Particle Life, grid/physics coupling, fire/smoke, fireworks, galaxy, boids, and SPH fluid.
- Static-library-first core with no graphics or platform dependency.
- Native Vulkan renderer using Win32, Xlib, or Cocoa/Metal surfaces.
- EpochPlatformEngine internal entrypoint and owner-thread application lifecycle.
- Optional EpochGui layout integration without changes to EpochGui.
- Headless sweep, deterministic replay validator, benchmark, tests, sanitizers, CMake package, presets, and cross-platform scripts.

## Validation performed before packaging

- GCC 14 C++23 Release build with warnings treated as errors.
- Full deterministic test suite.
- Static and shared library builds, exported ABI symbols, CMake installation, and an external `find_package` consumer.
- Clang C++23 build and ASan/UBSan suite.
- Vulkan renderer and Xlib surface translation units compiled with strict warnings against a controlled Vulkan API stub.
- EpochPlatformEngine lab translation units compiled with strict warnings against the public application/runtime contract.

The Vulkan runtime itself still requires validation on real Windows, Linux, and macOS GPU runners after publication; CI is configured to perform the Linux Vulkan compile and tag-driven Windows Vulkan package build.
