# EpochParticleEngine v0.1.2

Windows build-system reliability release.

## Fixed

- Removed the unnecessary pinned vcpkg baseline that failed with older, shallow, or nonstandard local vcpkg checkouts.
- Removed build-time Git history mutation and fetching from the user's vcpkg repository.
- Corrected Visual Studio instance parsing under Windows PowerShell 5.1 when `vswhere` returns multiple installations.
- Preserved automatic Visual Studio 2026 selection with Visual Studio 2022 fallback.
- Preserved explicit Ninja support while keeping Visual Studio as the default Windows generator.

## Upgrade

Extract the release into a clean directory and run `build.bat`. Existing failed `out` directories should not be reused.
