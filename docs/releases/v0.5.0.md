# EpochParticleEngine v0.5.0

v0.5.0 moves the deferred high-cost simulation systems plus galaxy integration onto Vulkan compute while preserving the deterministic CPU implementation as a fallback and replay reference.

## GPU compute

- Particle Life attraction/repulsion and integration run one invocation per particle.
- Boids alignment, cohesion, separation, pointer steering, and integration run on compute.
- Galaxy gravity, pointer interaction, bounds wrapping, and integration run on compute.
- SPH uses ordered density and pressure/force/integration dispatches.
- Conway Life evolves one cell per invocation from an immutable current grid.
- Compiled pipelines and submission resources are reused after first dispatch.

Every kernel writes a disjoint next-state range. Fixed-step inputs and a fence between dependent phases make results independent of rendered-frame cadence and workgroup execution order on the same GPU.

## Compatibility

The core library remains Vulkan-free. Headless consumers, unsupported devices, and shader failures use the existing CPU kernels. This release adds public compute-backend extension points and therefore advances the minor version.

GPU floating-point state is not claimed to be cross-vendor bit-identical. Deterministic CPU replay remains the portable reference.

## Validation

- Strict MSVC CPU Debug and Vulkan Release builds.
- Vulkan compute/readback probe on NVIDIA GeForce RTX 5080.
- Long-chunk versus short-chunk tick/state-hash equivalence for all five compute scenes.
- Assertion that every tested scene actually reported GPU compute rather than fallback.
- Deterministic CPU scene suite and Linux shared-library build.
- Normal `WM_CLOSE` shutdown with no retained process or executable handle.
