# EpochParticleEngine v0.1.4

Font sizing and DPI contract fix.

## Fixed

- Text size now means logical glyph height instead of an undocumented bitmap-cell multiplier.
- `RenderFrame` supports `TextSize { logical_height, dpi_scale }` and keeps the old float overload for compatibility.
- The interactive lab uses readable 12-18 logical-pixel font roles and derives row/footer spacing from the same metrics used by rendering.
- Per-monitor DPI changes update font scaling without distorting simulation coordinates.
- `screen_space.hpp` and `text.hpp` are included in installed SDK headers.

## Validation targets

- C++23 core build with warnings as errors.
- Deterministic scene suite.
- Logical text metric regression checks including 150% DPI.
- Installed-package consumer build.

## Upgrade

Extract into a clean directory and run:

```powershell
.\build.bat -Clean
.\run.bat
```
