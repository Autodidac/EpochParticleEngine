# EpochParticleEngine v0.1.5

Corrected Vulkan-lab build for the font/DPI release.

## Fixed

- Keeps the v0.1.4 logical font-height and per-monitor DPI corrections.
- Fixes GCC `-Wsubobject-linkage` in `EpochParticleLab` by moving stored application state types out of the anonymous namespace.
- Resolves Win32, Xlib, and Metal Vulkan surface-creation entrypoints through `vkGetInstanceProcAddr`.
- Enables `vulkan-loader[xlib]` on Linux so the Xlib surface extension is present in vcpkg-built loaders.
- Restores a warning-clean full Vulkan example build under strict CI.

## Upgrade

Extract into a clean directory and run:

```powershell
.\build.bat -Clean
.\run.bat
```
