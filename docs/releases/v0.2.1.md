# EpochParticleEngine v0.2.1

v0.2.1 is a build, packaging, and release-integrity update for the Particle Studio release line.

## Fixed

- Strict Windows shared-library builds no longer fail on MSVC C4251 diagnostics emitted for the intentional public standard-library value-type ABI.
- Source archive checksum files now contain the downloadable archive name instead of an ephemeral runner path.
- Release cleanup no longer attempts to delete an unrelated historical fix branch.

## Build and CI

- The public Windows wrapper accepts `-Shared` and records the selected linkage in `last-build.json`.
- The Unix wrapper accepts `--shared` and uses a distinct build directory.
- Windows CI now builds and tests the shared DLL with warnings as errors, installs it, builds an external `find_package` consumer, and runs that consumer.
- Release validation now requires the tag to agree with CMake, `version.hpp`, and `vcpkg.json`.
- Packaged checksums are verified before artifacts are uploaded.

## Validation

The release candidate passed:

- Debug static and Release shared MSVC warning-clean builds;
- all 11 test groups, including all 15 deterministic scenes;
- installed shared-SDK consumption from an external CMake project;
- replay and 240-tick headless validation;
- the optional benchmark and C++23 module facade; and
- MSVC static analysis over the core library.

Release assets contain the source archive and its portable SHA-256 checksum.
