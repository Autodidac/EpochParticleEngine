# EpochParticleEngine v0.4.0

v0.4.0 makes the fixed-step scheduler fully independent of how elapsed time is divided across rendered frames. The minor-version promotion reflects the added private scheduler state in the exported `Simulation` object layout.

## Root cause

The scheduler limited catch-up work per rendered frame, then discarded the remaining fixed-step backlog. It also clamped any single elapsed interval to 250 ms. Those safeguards avoided a spiral of death, but they made a long frame produce a different eventual simulation state than the same elapsed time divided across shorter frames.

## Fixed

- The catch-up limit is now a work budget only; unprocessed fixed steps remain in the accumulator.
- Long elapsed intervals are preserved rather than clamped.
- Accumulation saturates safely at the maximum representable nanosecond duration.
- Fractional scaled nanoseconds carry across calls instead of being rounded independently per frame.
- Pausing still intentionally ignores elapsed wall time while paused.
- Rendering telemetry, title refresh, and GPU glyph rasterization remain non-authoritative.

## Validation

The scheduler regression compares:

- one 500 ms elapsed interval with a two-step per-frame work budget; and
- fifty 10 ms elapsed intervals.

An additional nanosecond-level regression proves that two 1 ns frames at 0.5x time scale match one 2 ns frame in both tick and state hash.

After the retained backlog drains, both paths reach tick 50 with the same state hash. The release also passes the complete deterministic scene suite and cross-platform CI matrix.
