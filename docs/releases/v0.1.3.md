# EpochParticleEngine v0.1.3

Vulkan screen-space orientation fix.

## Fixed

- Corrected the Vulkan vertex shader's pixel-to-NDC Y conversion.
- `RenderFrame` content now uses the intended upper-left origin with positive Y downward.
- The simulation viewport, diagnostic panel, text, scene selector, and pointer hit-testing now agree vertically.

## Hardened

- Added `ScreenSpaceConvention` and `screen_to_vulkan_ndc` to the public C++23 API.
- Exported the coordinate contract through the optional `epoch.particle` module facade.
- Added compile-time top-left, center, and bottom-right mapping checks.
- Added shader-source assertions that reject the previous `1.0 - pixel.y` inversion.

## Upgrade

Extract the release into a clean directory, then run:

```powershell
.\build.bat -Clean
.\run.bat
```

The correction is isolated to EpochParticleEngine's Vulkan screen-to-clip conversion. EpochPlatformEngine and EpochGui require no changes.
